# v0.2.3 — correção crítica

A v0.2.2 tinha um erro de sintaxe JavaScript em `pointAtKm()` que interrompia
todo o script da aplicação. Isso fazia a APK abrir, mas nenhum botão responder
e o mapa não ser inicializado.

v0.2.3 substitui o bloco JavaScript por uma implementação limpa e validada,
mantendo:
- mapa + percurso KML;
- GPS;
- simulação;
- pontos de apoio;
- modo Caminhar;
- rotação;
- áudio;
- seleção de trecho.

A aplicação também mostra o erro no ecrã caso algum recurso local não possa ser carregado.
