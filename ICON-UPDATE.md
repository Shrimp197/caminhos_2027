# Atualização do ícone

A versão 0.3.1 passa a usar a imagem fornecida pelo utilizador como ícone da aplicação,
em vez do ícone genérico do Android.

Foram gerados os tamanhos de launcher Android e configurados `android:icon` e
`android:roundIcon` para `@mipmap/ic_launcher`.

Foi incrementado o versionCode para que o APK seja instalado como uma atualização.
