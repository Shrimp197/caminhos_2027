# Caminhos do Peregrino v1.0.2 — startup isolado

Correção do erro de arranque `Cannot read properties of null (reading "lat")`.

Alteração estrutural:
- o ecrã "Preparar caminhada" é inicializado antes do mapa;
- Leaflet só é iniciado quando o utilizador entra na navegação;
- os marcadores e referências de localização do utilizador não são tocados no arranque;
- percurso e base de apoios são carregados/validados antes da navegação;
- caminhos de emergência/partilha continuam protegidos quando ainda não existe GPS.
