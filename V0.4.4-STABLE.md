# v0.4.4 — Stable UI fix

Esta versão torna os controlos de preparação independentes de preenchimento dinâmico por JavaScript:
- Caminho do Centenário já aparece no HTML como percurso predefinido;
- Início e Fim já aparecem com as localidades disponíveis no HTML;
- Audio é um seletor de lista;
- Orientação é um seletor de lista;
- Personalizar pausa mostra campo editável de duração `00:00` e campo editável `0 km`;
- Apoios usam seleção múltipla por caixas de seleção;
- importação de KML/GPX continua disponível;
- o nome do percurso ativo é mostrado no topo.

O projeto mantém o track local e a base de apoios 2026.
