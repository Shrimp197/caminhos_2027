# Caminhos do Peregrino — v0.4.0 Stable Test

Esta versão integra a base de apoios 2026 fornecida para o projeto e transforma a
aplicação numa experiência de preparação + caminhada.

Incluído:
- novo ecrã inicial "Preparar caminhada";
- escolha de percurso/início/fim;
- áudio Normal / Imersivo / Silencioso;
- pausas por tempo/distância;
- opção de avisar sobre locais adequados para pausa;
- modo Caminhar;
- painel inferior flutuante/recolhível;
- orientação por norte ou direção da caminhada;
- GPS e matching ao track;
- estado no percurso/desvio;
- próximo apoio;
- "Próximos 10 km";
- "Onde dormir?";
- emergência;
- retomar caminhada;
- importação KML/GPX;
- biblioteca de percursos;
- base de apoios 2026 enriquecida com os 12 registos do ficheiro fornecido;
- `route_km` e `distance_to_track_m` calculados sobre o route.geojson ordenado,
  derivado do KML.

Importante:
- a base 2026 continua a ser base de teste, não garantia 2027;
- coordenadas ausentes permanecem ausentes;
- dados históricos/sazonais mantêm o respetivo estado;
- Google Maps continua apenas complemento para abrir uma localização;
- o track KML/GeoJSON continua a ser a referência do percurso.
