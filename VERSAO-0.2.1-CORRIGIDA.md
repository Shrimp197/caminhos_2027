# v0.2.1 — corrigida e imersiva

Esta build corrige o carregamento de ficheiros locais dentro da WebView usando
AndroidX WebViewAssetLoader e adiciona uma ponte nativa de voz (TextToSpeech).

Inclui:
- Modo Caminhar.
- Seleção de início/fim por localidades (camada inicial de teste).
- Simulação ao longo do track.
- Todos os apoios identificados na base de teste.
- Rotação por direção.
- Recentrar posição.
- Áudio nativo em português.
- Fallback para não bloquear a interface se os dados/mapa online falharem.

Objetivo: instalar esta build no Android e validar runtime antes de acrescentar os dados
oficiais de 2027 e os mapas offline.
