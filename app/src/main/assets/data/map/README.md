# OpenFreeMap Liberty style source

The bundled `openfreemap-liberty.json` is derived from the Liberty style published by the OpenFreeMap project.

Source repository: https://github.com/hyperknot/openfreemap-styles
Source path: `styles/liberty/style.json`
Source revision verified during implementation: `959df4602c8dc957cbd89c75464dda335e5b01db`

The OpenFreeMap styles repository states that its repository is MIT-licensed and that Liberty is derived from OSM Bright / OSM Liberty. The visible application attribution remains required and is kept in the map UI.

The bundled file keeps the original OpenFreeMap tile, sprite and glyph endpoints so the runtime continues to use OpenFreeMap data; only the style definition itself is local to the application.
