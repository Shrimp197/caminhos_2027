# Caminhos do Peregrino v1.1.0 — auditoria e correções

Branch: `v1.1-complete-audit-fix`

## Correções incluídas

- O **Caminho do Centenário** continua a ser o percurso predefinido.
- O **Percurso de teste — casa/trabalho** (3,042 km) passa a aparecer diretamente no seletor e na biblioteca de percursos.
- Mantida a possibilidade de importar KML/GPX; o seletor Android passa a usar `*/*` para evitar ficheiros GPX/KML apresentados como desativados por alguns gestores de documentos.
- A importação continua a validar o conteúdo/extensão como KML ou GPX antes de o guardar.
- Personalização de pausas por tempo: `95` passa a `95:00` ao terminar a edição; formatos `HH:MM` são convertidos corretamente para minutos para a lógica de alertas.
- Personalização por distância continua num campo numérico simples.
- **Todos** nos apoios passa a selecionar visualmente todas as categorias; retirar uma categoria retira o estado de Todos sem perder as restantes seleções.
- Mantida a seleção múltipla de categorias.
- Mantida a separação entre a lista geral de apoios/POI da etapa e o filtro específico **Próximos 10 km**.
- Mantida a função **Onde dormir?** limitada à etapa.
- Corrigida a função interna de mensagens/áudio usada pelos botões de teste, GPS, pausas e importação.
- Criada validação CI de JavaScript e dos dados essenciais antes do `assembleDebug`.
- Versão Android incrementada para `1.1.0` / versionCode `27`.

## Validação local efetuada

- Extração do JavaScript do `index.html`.
- `node --check` do JavaScript: **OK**.
- Verificação dos ficheiros de rota/apoios/GPX/KML no projeto.

## Limitação que permanece

A validação local não substitui um teste num dispositivo Android real. O próximo passo é deixar o GitHub Actions concluir a validação/build e, depois, instalar a APK gerada no telefone para o teste funcional final: seletor de percursos, importação GPX, pausas, filtros de apoios, orientação, áudio, GPS e navegação.
